# RelayBoard course lab

RelayBoard is a fictional incident-tracking service used throughout the course.

## Create your learner workspace

- PowerShell: `./setup-lab.ps1`
- Bash: `bash ./setup-lab.sh`

Both scripts refuse to overwrite an existing destination. They copy the starter, initialize an isolated Git repository, create the `course-start` tag, and switch to a `learner-work` branch.

The starter intentionally fails several tests. Capture that baseline and work through the modules. Use `solution/` only after attempting the relevant labs.
