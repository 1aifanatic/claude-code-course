THE OPERATING LOOP

Five controls turn speed into trustworthy delivery.

Claude Code is most effective when every action sits inside a visible loop with bounded authority and a real stopping signal.

01

Observe

Gather only relevant repository evidence.

02

Frame

Turn ambiguity into a reviewable contract.

03

Act

Make a small, reversible change.

04

Verify

Run checks capable of proving failure.

05

Handoff

Expose decisions, risk, evidence, and recovery.

Path 1 · Operate

Work like an accountable engineer

01Orient · 25 minHow Claude Code actually works

Replace magical thinking with a controllable model of observe, decide, act, and verify.

Stable02Explore · 30 minMap an unfamiliar repository

Find the change surface, contracts, and verification path before opening the editor.

Stable03Frame · 35 minTurn ambiguity into specifications and plans

Make the problem reviewable before asking Claude to make it real.

Stable04Implement · 30 minImplement through bounded feedback loops

Keep each change small enough to inspect, test, redirect, and recover.

Stable05Verify · 35 minVerify, debug, review, and recover

Turn claims of completion into evidence that could prove the work wrong.

Stable06Control · 30 minControl context, sessions, cost, and compaction

Treat attention as a finite engineering resource and sessions as disposable workspaces.

Stable07Protect · 35 minPermissions, sandboxing, secrets, and trust boundaries

Give Claude enough authority to work—never enough to make review meaningless.

Path 2 · Configure

Turn good habits into project infrastructure

Place durable context, procedures, specialists, enforcement, and integrations at the right layer.

08Instruct · 30 minEngineer effective CLAUDE.md, rules, and memory

Put durable guidance where it loads reliably without drowning the task.

Stable09Specialize · 35 minBuild reusable skills

Turn a repeatedly useful procedure into on-demand, testable project knowledge.

Stable10Delegate · 35 minDesign and control subagents

Delegate focused work to isolated contexts without giving away coordination or judgment.

Stable11Enforce · 35 minAutomate deterministic safeguards with hooks

Run the right check at the right lifecycle event without relying on the model to remember.

Stable12Connect · 35 minConnect and package capabilities with MCP and plugins

Separate access to external systems from the knowledge that makes that access useful.

Path 3 · Scale

Coordinate repeatable, governed delivery

Use isolation, automation, measurement, and operating controls to move beyond a single interactive session.

13Coordinate · 30 minCoordinate parallel sessions, worktrees, and Git

Increase throughput by isolating ownership—not by multiplying edits to the same problem.

Advanced14Automate · 35 minRun Claude Code programmatically and in CI

Convert an interactive workflow into bounded automation with machine-readable outcomes.

Advanced15Govern · 30 minEstablish team governance

Scale evidence, controls, ownership, and learning—not merely licenses and token volume.

Advanced16Integrate · 60 minCapstone: deliver a trusted repository change

Combine only the context, authority, extensions, and automation your outcome can justify.
