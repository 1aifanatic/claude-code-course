← Course homeGLOSSARY

Use precise words for powerful systems.

Search the course vocabulary. Definitions favor practical meaning over exhaustive product reference.

Acceptance criterion

An observable condition that must be satisfied before work is accepted.

Agent team

Experimental coordination of independent Claude Code sessions that share tasks and can communicate.

Agentic loop

The cycle of interpreting, acting through tools, observing, and deciding what to do next.

Auto memory

Machine-local notes Claude records and may load across sessions for a repository.

Blast radius

The maximum scope of harm or unintended change an action could cause.

Checkpoint

A recoverable code or evidence state created between bounded implementation steps.

CLAUDE.md

A file supplying persistent project, user, or organization instructions.

Compaction

Summarization of older session context to create space for continued work.

Context window

The finite set of instructions, messages, files, outputs, skills, and tool information available to the model.

Critical criterion

A requirement whose failure blocks acceptance and cannot be offset by other points.

Evidence packet

A collection of specifications, diffs, tests, reviews, and recovery notes supporting a change.

Hook

An event-triggered handler that runs at a defined Claude Code lifecycle point.

Invariant

A condition that must remain true across a change.

Least privilege

Limiting access to the minimum authority needed for the task.

Managed settings

Organization-controlled Claude Code configuration users cannot override.

MCP

Model Context Protocol, a standard for exposing structured tools and data to AI applications.

Non-interactive mode

Single-run Claude Code execution through -p or --print, commonly used in scripts and CI.

Path-scoped rule

Instructions under .claude/rules that load only for matching files or directories.

Permission mode

The baseline behavior for allowing, asking about, or denying tool use.

Plugin

A shareable bundle of Claude Code skills, subagents, hooks, and MCP configuration.

Prompt injection

Untrusted content intended to redirect model behavior or induce unauthorized actions.

Provenance

The exact source supporting a fact or claim.

Red-capable test

A check known to fail in the defective or missing-behavior state.

Regression

Previously working behavior broken by a change.

Sandbox

An OS-enforced boundary around command filesystem and network access.

Skill

On-demand reusable instructions, knowledge, or workflows rooted in SKILL.md.

Structured output

Machine-readable output constrained for programmatic consumption.

Subagent

A bounded worker operating in a separate context and returning a result to its parent.

Tool

A capability Claude can invoke, such as reading, editing, running a command, or calling MCP.

Trust boundary

A point where data, authority, identity, or control crosses between differently trusted domains.

Vertical slice

A small end-to-end unit of behavior that provides meaningful evidence.

Worktree

An additional Git working directory used to isolate branch state for concurrent work.
