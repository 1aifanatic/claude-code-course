# Claude Code team-readiness checklist

## Scope

- [ ] Approved repositories, data classes, environments, and use cases are documented.
- [ ] Prohibited data and actions are explicit.
- [ ] Tasks are mapped to risk tiers and matching autonomy.

## Controls

- [ ] Managed, user, and project settings have named owners.
- [ ] Permission, sandbox, MCP, plugin, hook, and CI boundaries are tested.
- [ ] Secrets and untrusted inputs have technical protections.
- [ ] High-impact actions require accountable approval and a recovery plan.

## Operations

- [ ] Telemetry covers usage, cost, tool actions, errors, and denied operations.
- [ ] Outcome metrics include review effort, accepted changes, defects, and rollback.
- [ ] Incident, exception, and kill-switch procedures are rehearsed.
- [ ] Feature status and official sources have a review cadence.

## Learning

- [ ] Failures and review findings update shared instructions or training through reviewable changes.
- [ ] Shared skills, agents, hooks, MCP servers, and plugins have maintainers and removal plans.
